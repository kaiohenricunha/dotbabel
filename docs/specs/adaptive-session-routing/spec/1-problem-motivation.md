# §1 — Problem / Motivation

Users currently choose the main session's model and reasoning effort themselves. Artifact compute metadata does not route an ordinary prompt. The owner requests automatic, reversible selection before execution, independently of subagent configuration.

The target experience is installation, explicit project opt-in, and ordinary natural-language prompts. The selected harness executes each original submission exactly once in its existing conversation. Model Intelligence remains the single deterministic resolver; this spec owns classification and application.

Correctness includes truthful effective configuration, preserved manual choices, project isolation and no new inference or network work when disabled. §7 makes these claims testable.
