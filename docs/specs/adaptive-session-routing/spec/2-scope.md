# §2 — Scope

## In scope

Project-local activation; structured task classification; independent model and effort demand; shared resolver integration; Claude mod and Codex App Server integrations where verified; user controls; explanations; runtime verification; setup and rollback documentation.

## Boundaries

The original [Model Intelligence spec](../../model-intelligence/README.md) owns evidence, requirements, policy, resolution, artifact binding, migration and recommendation. Its advisory commands stay advisory. This linked spec owns opt-in main-session application only.

No new provider gateway, credential manager, model registry, ranking benchmark, subscription manager, automatic paid classifier, subagent configuration rewrite or global runtime configuration switch is introduced. No unsupported runtime gets a fabricated binding.

Stock Codex CLI support must be established independently of App Server. A managed client is a distinct execution mode, explicitly named in setup and status.
